Keyboard shortcut to open and close the search:

Written in mpv’s key format, for example Meta+f for ⌘F or Ctrl+Shift+s. Leave empty for no shortcut. Takes effect in new player windows.

Use 0 to jump exactly to the moment the subtitle appears.

Location of ffmpeg:

ffmpeg is only used to read subtitles embedded in the video file (for example in MKV or MP4). Leave empty to look in the usual Homebrew and MacPorts locations.
